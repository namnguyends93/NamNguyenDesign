Cách dùng

• Rê chuột lên chữ → viền xanh → bấm vào để gõ sửa.
• Nút 🖼 Đổi ảnh trên mỗi ảnh để thay ảnh (có ghi kích thước nên xuất).
• Nút ← → trên slider vẫn bấm được để sửa từng project.
• Ô chọn trang ở trên cùng: sửa trang chủ hoặc từng project / bài Nhật ký (thêm, xoá, đổi thứ tự module ở bảng này).
• Xong bấm Lưu. Đưa lên mạng ở Admin → Xuất bản.
